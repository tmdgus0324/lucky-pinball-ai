## Form이란?

**사용자로부터 입력을 받기 위해 사용**하는 HTML 요소입니다.

```jsx
<form>
  <label>
    이름:
    <input type="text" name="name" />
  </label>
  <button type="submit">제출</button>
</form>
```

## Controlled Components (제어 컴포넌트)

**값이 React의 통제를 받는 Input Form Element**입니다.

- HTML의 `input`, `textarea`, `select` 태그 등은 원래 **각자 자기 상태를 따로 관리**합니다.
- 제어 컴포넌트는 **모든 데이터를 React의 state에서 관리**합니다. 값을 바꿀 때는 `setState`(함수 Component에서는 `useState` Hook의 set 함수)를 사용합니다.

```jsx
function NameForm(props) {
  const [value, setValue] = useState('');

  // onChange 콜백 함수의 첫 번째 파라미터인 event는 이벤트 객체입니다.
  // event.target은 이벤트가 발생한 대상(여기서는 input element),
  // event.target.value는 그 대상의 value 속성값(= input에 입력된 값)입니다.
  const handleChange = (event) => {
    setValue(event.target.value);
  };

  const handleSubmit = (event) => {
    alert('입력한 이름: ' + value);
    event.preventDefault();   // form 제출 시 기본 동작(페이지 새로고침)을 막습니다.
  };

  // React Component의 state 값을 input에 넣어 줍니다.
  // handleChange에서 setValue로 새 값을 state에 저장하면 다시 렌더링되면서 화면에 반영됩니다.
  return (
    <form onSubmit={handleSubmit}>
      <label>
        이름:
        <input type="text" value={value} onChange={handleChange} />
      </label>
      <button type="submit">제출</button>
    </form>
  );
}
```

> **AI 코멘트**
>
> 제어 컴포넌트는 입력값이 항상 React state와 같아서 **검증, 형식 변환, 다른 UI와의 연동**(입력값에 따라 버튼 활성화 등)이 쉽습니다. 대신 키를 누를 때마다 `onChange` → `setState` → 렌더링이 일어납니다. 필드가 아주 많은 큰 폼에서는 이것이 성능과 코드량의 부담이 되어, **React Hook Form** 같은 라이브러리(비제어 방식 + ref 기반)를 많이 씁니다. 단순한 폼이면 제어 컴포넌트로 충분합니다.
>
> 참고로 React의 `onChange`는 HTML의 `change` 이벤트(포커스를 잃을 때)와 달리 **입력할 때마다** 호출됩니다.

## Textarea 태그

```jsx
function RequestForm(props) {
  const [value, setValue] = useState('요청사항을 입력하세요.');

  const handleChange = (event) => {
    setValue(event.target.value);
  };

  const handleSubmit = (event) => {
    alert('입력한 요청사항: ' + value);
    event.preventDefault();
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        요청사항:
        <textarea value={value} onChange={handleChange} />
      </label>
      <button type="submit">제출</button>
    </form>
  );
}
```

## Select 태그

**Drop-down 목록**을 보여주기 위한 HTML 태그입니다.

```jsx
function FruitSelect(props) {
  const [value, setValue] = useState('grape');

  const handleChange = (event) => {
    setValue(event.target.value);
  };

  const handleSubmit = (event) => {
    alert('선택한 과일: ' + value);
    event.preventDefault();
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        과일을 선택하세요:
        <select value={value} onChange={handleChange}>
          <option value="apple">사과</option>
          <option value="banana">바나나</option>
          <option value="grape">포도</option>
          <option value="watermelon">수박</option>
        </select>
      </label>
      <button type="submit">제출</button>
    </form>
  );
}
```

**여러 개의 옵션을 선택**하게 하려면 `multiple`에 배열을 `value`로 줍니다.

```jsx
<select multiple={true} value={['B', 'C']}>
```

**세 태그의 공통 패턴** — 모두 `value` + `onChange` 로 state와 연결합니다.

```jsx
<input type="text" value={value} onChange={handleChange} />

<textarea value={value} onChange={handleChange} />

<select value={value} onChange={handleChange}>
  <option value="apple">사과</option>
  <option value="banana">바나나</option>
  <option value="grape">포도</option>
  <option value="watermelon">수박</option>
</select>
```

## File input 태그

**하나 또는 여러 개의 파일을 선택**할 수 있게 해 주는 HTML 태그입니다.

> **AI 코멘트**
>
> `<input type="file" />`은 값이 읽기 전용이라 React가 값을 정할 수 없어서 **비제어 컴포넌트(Uncontrolled Component)** 입니다. 선택된 파일은 `event.target.files`나 `ref`로 읽습니다. 이 챕터 예제 코드에 남아 있는 "file은 react에서는 Uncontrolled Component 이다"라는 주석이 이 뜻입니다.

## Multiple Inputs

여러 입력을 한 폼에서 다루는 예제입니다. 체크박스는 `value`가 아니라 **`checked`** 를 사용합니다.

```jsx
function Reservation(props) {
  const [haveBreakfast, setHaveBreakfast] = useState(true);
  const [numberOfGuest, setNumberOfGuest] = useState(2);

  const handleSubmit = (event) => {
    alert(`아침식사 여부: ${haveBreakfast}, 방문객 수: ${numberOfGuest}`);
    event.preventDefault();
  };

  return (
    <form onSubmit={handleSubmit}>
      <label>
        아침식사 여부:
        <input
          type="checkbox"
          checked={haveBreakfast}
          onChange={(event) => {
            setHaveBreakfast(event.target.checked);
          }} />
      </label>
      <br />
      <label>
        방문객 수:
        <input
          type="number"
          value={numberOfGuest}
          onChange={(event) => {
            setNumberOfGuest(event.target.value);
          }} />
      </label>
      <button type="submit">제출</button>
    </form>
  );
}
```

> **AI 코멘트**
>
> `<input type="number">`라도 `event.target.value`는 **문자열**입니다. 위 예제처럼 그대로 state에 넣으면 숫자가 아니라 문자열이 저장되므로, 계산에 쓸 때는 `Number(...)`로 바꿉니다. 체크박스가 `value`가 아니라 `checked`를 쓰는 점도 자주 헷갈립니다.
>
> 입력 필드가 여럿일 때는 필드마다 핸들러를 만드는 대신, 입력의 `name` 속성을 이용해 하나로 합칠 수 있습니다.
>
> ```jsx
> const [form, setForm] = useState({ name: '', gender: '남자' });
> const handleChange = (e) => setForm({ ...form, [e.target.name]: e.target.value });
> // <input name="name" ... />, <select name="gender" ... /> — name과 state의 키 이름을 같게 맞춥니다.
> ```

## Input Null Value

제어 컴포넌트에 `value`를 지정하면 사용자가 값을 바꿀 수 없습니다. 하지만 `value`에 **`null`(또는 `undefined`)** 을 넘기면 **입력이 가능한 상태**로 풀립니다.

```jsx
ReactDOM.render(<input value="hi" />, rootNode);   // 고정되어 수정 불가

setTimeout(function () {
  ReactDOM.render(<input value={null} />, rootNode);   // 1초 뒤: 다시 수정 가능
}, 1000);
```

> **AI 코멘트**
>
> `value={null}`은 요즘은 **경고 대상**입니다(React가 "제어/비제어가 중간에 바뀌었다"고 알려 줍니다). 값이 아직 없을 때는 `null`/`undefined` 대신 **빈 문자열 `''`로 초기화**하는 것이 안전합니다. 위 원문 예제는 이 동작을 설명하기 위한 것이고, 실제 코드에서는 쓰지 않는 패턴입니다.

## 이 챕터의 예제 (SignUp)

**데모** 탭의 `SignUp`은 위 내용을 한 폼에 모은 것입니다.

- **요청사항**(`textarea`), **이름**(`input`), **성별**(`select`) 세 값을 각각 `useState`로 관리하는 **제어 컴포넌트**입니다.
- **제출**을 누르면 `alert`로 입력한 값을 보여주고, `event.preventDefault()`로 페이지가 새로고침되지 않게 합니다.
- 맨 아래 `<input type="file" />` 은 **비제어 컴포넌트**입니다.

> **AI 코멘트**
>
> `event.preventDefault()`를 빼면 form을 제출할 때 페이지가 새로고침되어 입력한 state가 사라집니다. 실제 서비스에서는 `alert` 대신 `fetch`로 서버에 보내고, 서버 검증 실패 같은 결과도 화면에 보여줘야 합니다. 이 프로젝트의 참가자 등록 폼(`RegistrationForm`)이 이 흐름입니다. `onSubmit`에서 `preventDefault()` 후 `api.registerPlayer(...)`를 호출하고, 결과나 오류를 상태 문구로 보여줍니다.
