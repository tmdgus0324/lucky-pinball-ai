## 시작하기 전에 ① React란?

**React = A JavaScript Library for building user interfaces**
사용자 인터페이스(UI)를 만들기 위한 자바스크립트 라이브러리입니다.

- **사용자 인터페이스(UI)**: 사용자와 컴퓨터 프로그램이 상호작용하기 위한 입력과 출력을 제어해 주는 것
- **라이브러리 vs 프레임워크**: React는 대표적인 UI 라이브러리이고, Angular·Vue.js는 프레임워크로 분류합니다.
  - 라이브러리는 개발자가 필요한 부분만 가져다 쓰는 형태(**제어권한이 개발자에게** 있음)
  - 프레임워크는 **프레임워크에 제어권한**이 있습니다.

### 장점

- 빠른 업데이트와 렌더링 속도
- **Virtual DOM**: 웹페이지를 담고 있는 하나의 객체
- **Component-Based**: 컴포넌트들을 모아서 개발
- **재사용성(Reusability)**: 의존성 문제, 호환성 문제 등이 생길 수 있지만 컴포넌트 단위로 재사용
- 개발 기간 단축, 유지보수 용이(버그를 찾기 쉬움), Meta(Facebook)가 관리
- **React Native**로 모바일 앱 개발까지 확장 가능

### 단점

- Virtual DOM, JSX, Component, State, Props 등 학습량이 많다.
- 계속 달라진다(버전별 차이).
- 상태 관리의 복잡도가 높다. 그래서 외부 상태관리 라이브러리를 쓰는 경우가 많다.

> **AI 코멘트**
>
> React는 **화면(UI)을 만드는 부분**만 담당합니다. 실무에서는 라우팅, 데이터 불러오기, 빌드 같은 나머지를 함께 제공하는 프레임워크(Next.js 등)나 빌드 도구(Vite) 위에서 쓰는 경우가 많습니다. 이 프로젝트도 React + Vite + React Router를 직접 조합한 구성입니다.
>
> "라이브러리라서 제어권이 개발자에게 있다"는 말은 곧 **"구조를 스스로 정해야 한다"** 는 뜻이기도 합니다. 프로젝트가 커질수록 폴더 구조와 상태 관리 방식을 직접 책임지게 됩니다.

## 시작하기 전에 ② 개발환경과 버전 참고

**준비물**: Node.js, npm, VS Code, (깃 연동용) 소스트리

**CRA(create-react-app)로 프로젝트 만들기**

```bash
npx create-react-app my-app     # 프로젝트 생성
cd my-app
npm start                       # localhost:3000 에서 실행
```

- `npx create-react-app my-app` 에서 에러가 나면 패키지 설치 과정을 건너뛴 것입니다 → `npm -g install create-react-app` 으로 설치한 뒤 다시 시도합니다.
- 실습의 핵심: ReactDOM의 `render` 함수로 React Component를 DOM Container에 렌더링하고, Component의 **state가 변경되는 예시**를 확인합니다.

**터미널에서 npm 실행 시 권한 오류가 날 때 (Windows)**

> `npm : 이 시스템에서 스크립트를 실행할 수 없으므로 ...npm.ps1 파일을 로드할 수 없습니다.`

권한 문제입니다. PowerShell을 **관리자 모드**로 열고 `Set-ExecutionPolicy RemoteSigned` 로 권한을 변경한 뒤 사용합니다.

**React는 버전별로 차이가 있다 — 17버전으로 맞추기**

```bash
npm uninstall react react-dom
npm install react@17.0.2 react-dom@17.0.2
```

`index.js`의 렌더링 방식도 버전에 따라 다릅니다.

```jsx
// React 18 방식
const root = ReactDOM.createRoot(document.getElementById('root'));
root.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>
);

// React 17 방식
ReactDOM.render(
  <React.StrictMode>
    <App />
  </React.StrictMode>,
  document.getElementById('root')
);
```

**`npm install --save styled-components` 에서 에러가 날 때**

- `--legacy-peer-deps`: 기존 라이브러리의 peer 버전 충돌을 무시하고 설치합니다(17버전 기준으로 추가하면 정상 테스트 가능).
- `--force`: package.json / package-lock.json 에 여러 의존 버전을 추가하면서 강제로 설치합니다.

> **AI 코멘트**
>
> - **CRA(create-react-app)** 는 React 팀이 2025년에 더 이상 권장하지 않고 지원을 종료하겠다고 안내했습니다. 지금은 Vite 같은 빌드 도구나 프레임워크로 시작하는 것이 일반적이고, 이 프로젝트도 Vite를 씁니다. 개념 공부에는 영향이 없지만 새 프로젝트를 만들 때는 CRA를 피하는 편이 좋습니다.
> - 위의 17버전 `ReactDOM.render`는 React 18에서 `createRoot`로 바뀌었고, **React 19에서는 `ReactDOM.render`가 제거**됐습니다. 새로 쓸 때는 위 "React 18 방식(`createRoot`)"을 씁니다.
> - "17버전으로 맞추기"는 강의 예제를 그대로 따라가기 위한 선택입니다. 새 프로젝트라면 최신 버전을 쓰는 편이 낫습니다.

## 시작하기 전에 ③ HTML · JavaScript 기초

**HTML과 SPA**

- **SPA(Single Page Application)**: 하나의 페이지로 구성하는 애플리케이션
- 기존 방식은 페이지마다 html 파일이 따로 있었고, SPA는 접속 시 `body`에 content를 **동적으로** 채워 넣습니다.

**JavaScript** — ECMAScript(ES6 버전을 표준으로 함). HTML이 뼈대를 구성하고, JavaScript는 런타임에 코드가 해석·실행됩니다.

1. **자료형**: 동적 타이핑(Dynamic Typing). 변수 선언은 `var`, `let`

   ```js
   let u1;                    // Undefined type
   let u2 = undefined;
   let obj = { a: "apple", b: "banana", c: "carrot" };   // Object type
   ```

2. **연산자**
   - 대입 연산자 `=`: 오른쪽에서 왼쪽으로 대입
   - 산술 연산자: `a ** b`(거듭제곱, 2의 4승 = 16), `a *= b`(`a = a * b`)
   - 증가/감소 연산자: postfix `a++` / prefix `++a`

     ```js
     let a = 1; let b = a++;   // a는 2, b는 1
     let c = 1; let d = ++c;   // c는 2, d는 2
     ```

   - 관계 연산자: `<`, `>`, `<=`, `>=`
   - 일치 연산자: `===`, `!==` (값과 자료형이 모두 같은지/다른지)
   - 이진 논리 연산자: `a && b`, `a || b`
   - 조건(삼항) 연산자: `조건식 ? 참일 때 : 거짓일 때`

3. **함수**

   ```js
   // function statement
   function sum(a, b) {
     return a + b;
   }

   // arrow function expression
   const multiply = (a, b) => {
     return a * b;
   };
   ```

> **AI 코멘트**
>
> - 요즘 JavaScript에서는 `var`를 거의 쓰지 않습니다. 기본은 `const`, 값을 다시 대입해야 할 때만 `let`입니다. `var`는 블록이 아니라 함수 단위 스코프라 의도치 않게 값이 바깥으로 새기 쉽습니다.
> - 비교는 `==`보다 `===`가 안전합니다. `==`는 타입을 바꿔서 비교하기 때문에 `0 == ''`, `'1' == 1`이 모두 `true`가 됩니다. 이 챕터들의 예제 코드에도 `==`를 쓴 곳이 남아 있는데, 학습 당시 코드를 그대로 둔 것입니다.
>
> Java 개발자 관점에서 하나 짚으면, JS의 `&&`/`||`는 boolean이 아니라 **피연산자 값 자체**를 돌려줍니다(`0 || 5`는 `5`). 이 성질이 JSX의 조건부 렌더링(`조건 && <컴포넌트 />`)에 그대로 쓰입니다(9장).

## JSX란?

**JSX = A syntax extension to JavaScript** — 자바스크립트 확장 문법입니다. (JavaScript + XML/HTML)

```jsx
const element = <h1>Hello, world!</h1>;
```

**JSX의 역할**: JSX는 결국 `React.createElement()` 호출로 변환됩니다.

```js
React.createElement(
  type,
  [props],
  [...children]
)
```

### JSX 사용 vs 미사용 비교

```jsx
// JSX를 사용한 코드
const element = (
  <h1 className="greeting">
    Hello, world!
  </h1>
);

// JSX를 사용하지 않은 코드
const element = React.createElement(
  'h1',
  { className: 'greeting' },
  'Hello, world!'
);

// React.createElement()의 결과로 아래와 같은 객체(Element)가 생성됩니다.
const element = {
  type: 'h1',
  props: {
    className: 'greeting',
    children: 'Hello, world!'
  }
};
```

> **AI 코멘트**
>
> JSX는 HTML이 아니라 **JavaScript 문법의 확장**이라서 HTML과 다른 점이 있습니다.
>
> - `class` 대신 `className`, `for` 대신 `htmlFor`, 속성 이름은 camelCase(`onClick`, `tabIndex`)
> - 컴포넌트는 **루트 요소 하나**만 반환해야 합니다. 감쌀 요소가 필요 없으면 `<>...</>`(Fragment)를 씁니다.
> - `{}` 안에는 값을 만드는 **표현식**만 들어갑니다. `if`/`for` 같은 문장은 넣을 수 없어서, 조건은 삼항 연산자·`&&`로, 반복은 `map`으로 씁니다(9~10장).

## JSX의 장점

- **간결한 코드**: `` createElement('div', null, `Hello, ${name}`) `` 를 `<div>Hello, {name}</div>` 로 대체할 수 있습니다.
- **가독성**이 좋습니다.
- **Injection Attack(XSS) 방어, 보안성**: `{}` 안에 들어가는 변수는 문자열로 변환되어 출력되기 때문에 악의적인 입력이 코드로 실행되지 않습니다.

  ```jsx
  const title = response.potentiallyMaliciousInput;
  // 이 코드는 안전합니다.
  const element = <h1>{title}</h1>;
  ```

> **AI 코멘트**
>
> `{}`로 출력하는 값은 React가 자동으로 이스케이프해 주므로 일반적인 XSS는 막아 줍니다. 다만 "완전히 안전하다"는 뜻은 아닙니다. HTML을 그대로 넣는 `dangerouslySetInnerHTML`은 이 보호를 우회하고(이름에 "위험"이 들어간 이유입니다), `href={사용자입력}`처럼 링크 주소에 사용자 입력을 넣는 경우에도 `javascript:` 주소 같은 별도의 위험이 있습니다.

## JSX 사용하기

**`{}`로 자바스크립트 값 넣기**

```jsx
const name = '소플';
const element = <h1>안녕, {name}</h1>;

ReactDOM.render(element, document.getElementById('root'));
```

**태그의 속성(attribute)에 값 넣기**

```jsx
// 큰따옴표 사이에 문자열을 넣거나
const element = <div tabIndex="0"></div>;
// 중괄호 사이에 자바스크립트 코드를 넣습니다.
const element = <img src={user.avatarUrl}></img>;
```

**자식(children) 정의하기**

```jsx
const element = (
  <div>
    <h1>안녕하세요</h1>
    <h2>열심히 리액트를 공부해 봅시다.</h2>
  </div>
);
```
