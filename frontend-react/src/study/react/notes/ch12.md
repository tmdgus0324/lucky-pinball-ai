## Shared State란?

**공유된 상태**입니다.

- State에 있는 데이터를 **여러 개의 하위 Component에서 공통으로** 사용하는 경우입니다.
- 하위 Component들이 **공통된 부모 Component의 state를 공유**해서 사용합니다.

> **AI 코멘트**
>
> 핵심 원칙은 **단일 진실 공급원(single source of truth)** 입니다. 같은 값을 두 곳이 각자 state로 들고 있으면 반드시 어긋납니다. 그래서 공통 부모에 값을 하나만 두고, **값은 props로 아래로, 변경 요청은 콜백으로 위로** 흐르게 합니다(단방향 데이터 흐름).

## 하위 Component에서 State 공유하기

물이 끓는지 알려 주는 Component

```jsx
function BoilingVerdict(props) {
  if (props.celsius >= 100) {
    return <p>물이 끓습니다.</p>;
  }
  return <p>물이 끓지 않습니다.</p>;
}
```

섭씨 온도를 입력받아 `BoilingVerdict`에 넘기는 `Calculator`

```jsx
function Calculator(props) {
  const [temperature, setTemperature] = useState('');

  const handleChange = (event) => {
    setTemperature(event.target.value);
  };

  return (
    <fieldset>
      <legend>섭씨 온도를 입력하세요:</legend>
      <input value={temperature} onChange={handleChange} />
      <BoilingVerdict celsius={parseFloat(temperature)} />
    </fieldset>
  );
}
```

## 입력 Component 추출하기

섭씨/화씨 두 개의 입력창이 필요해서, 입력 부분을 `TemperatureInput` Component로 **추출**합니다.

```jsx
const scaleNames = {
  c: '섭씨',
  f: '화씨'
};

function TemperatureInput(props) {
  const [temperature, setTemperature] = useState('');

  const handleChange = (event) => {
    setTemperature(event.target.value);
  };

  return (
    <fieldset>
      <legend>
        온도를 입력해 주세요(단위:{scaleNames[props.scale]}):
      </legend>
      <input value={temperature} onChange={handleChange} />
    </fieldset>
  );
}
```

추출한 Component를 사용하도록 `Calculator`를 바꿉니다.

```jsx
function Calculator(props) {
  return (
    <div>
      <TemperatureInput scale="c" />
      <TemperatureInput scale="f" />
    </div>
  );
}
```

**문제**: 두 입력창이 **각자 자기 state**를 가지고 있어서, 한쪽에 입력해도 다른 쪽이 따라 바뀌지 않습니다. → state를 부모로 끌어올립니다.

**섭씨 ↔ 화씨 변환 함수**

```jsx
function toCelsius(fahrenheit) {
  return (fahrenheit - 32) * 5 / 9;
}

function toFahrenheit(celsius) {
  return (celsius * 9 / 5) + 32;
}
```

`tryConvert`는 온도 값과 **변환 함수를 파라미터로 받아** 값을 변환해서 리턴합니다.

```jsx
function tryConvert(temperature, convert) {
  const input = parseFloat(temperature);
  if (Number.isNaN(input)) {
    return '';
  }
  const output = convert(input);
  const rounded = Math.round(output * 1000) / 1000;
  return rounded.toString();
}

tryConvert('abc', toCelsius);        // empty string을 리턴
tryConvert('10.22', toFahrenheit);   // '50.396'을 리턴
```

## Shared State 적용하기 — Lifting State Up

**state를 공통 부모로 끌어올립니다.** 먼저 `TemperatureInput`이 온도 값을 자기 state가 아니라 **props에서** 가져오게 바꿉니다.

```jsx
// 변경 전: <input value={temperature} onChange={handleChange} />
<input value={props.temperature} onChange={handleChange} />
```

온도 값이 바뀔 때는 props로 받은 `onTemperatureChange` 함수를 통해 **변경된 값을 상위 Component로 전달**합니다.

```jsx
const handleChange = (event) => {
  // 변경 전: setTemperature(event.target.value);
  props.onTemperatureChange(event.target.value);
};
```

**최종적으로 완성된 `TemperatureInput`** — state는 제거되었고, 오직 상위 Component가 제공한 값만 받습니다.

```jsx
function TemperatureInput(props) {
  const handleChange = (event) => {
    props.onTemperatureChange(event.target.value);
  };

  return (
    <fieldset>
      <legend>
        온도를 입력해 주세요(단위:{scaleNames[props.scale]}):
      </legend>
      <input value={props.temperature} onChange={handleChange} />
    </fieldset>
  );
}
```

## Calculator Component 변경하기

공유되는 state(온도 `temperature`와 마지막으로 입력한 단위 `scale`)는 **공통 부모인 `Calculator`** 가 가집니다.

```jsx
function Calculator(props) {
  const [temperature, setTemperature] = useState('');
  const [scale, setScale] = useState('c');

  const handleCelsiusChange = (temperature) => {
    setTemperature(temperature);
    setScale('c');
  };

  const handleFahrenheitChange = (temperature) => {
    setTemperature(temperature);
    setScale('f');
  };

  const celsius = scale === 'f' ? tryConvert(temperature, toCelsius) : temperature;
  const fahrenheit = scale === 'c' ? tryConvert(temperature, toFahrenheit) : temperature;

  return (
    <div>
      <TemperatureInput
        scale="c"
        temperature={celsius}
        onTemperatureChange={handleCelsiusChange} />
      <TemperatureInput
        scale="f"
        temperature={fahrenheit}
        onTemperatureChange={handleFahrenheitChange} />
      <BoilingVerdict
        celsius={parseFloat(celsius)} />
    </div>
  );
}
```

> **AI 코멘트**
>
> 이 예제에서 `celsius`와 `fahrenheit`는 state가 아니라 **`temperature`와 `scale`에서 계산해 낸 값**입니다(`tryConvert`). state에는 "사용자가 마지막으로 입력한 값과 단위"만 두고 나머지는 파생시키는 것이 좋은 설계입니다. 파생 값까지 state로 두면 동기화 코드를 따로 써야 하고, 어긋날 위험이 생깁니다.

## 이 챕터의 예제 (Calculator / TemperatureInput)

**데모** 탭에서 직접 확인해 보세요.

- 섭씨 칸에 `100`을 입력하면 화씨 칸이 `212`로 바뀌고 "물이 끓습니다."가 나옵니다.
- 화씨 칸에 입력해도 섭씨 칸이 따라 바뀝니다.
- 두 입력창은 state가 없고, **`Calculator`의 `temperature`/`scale` 하나**만 공유합니다. 입력이 바뀌면 `onTemperatureChange`로 부모에게 알리고, 부모가 변환해서 두 칸에 다시 내려줍니다. (데이터는 위로 올라가고, 값은 아래로 내려갑니다.)

> **AI 코멘트**
>
> 끌어올리기는 두세 단계까지는 좋지만, 값을 쓰는 컴포넌트가 깊이 떨어져 있으면 **중간 컴포넌트들이 쓰지도 않는 props를 계속 전달**하게 됩니다(prop drilling). 이때의 선택지는 합성(13장), Context(14장), 상태 관리 라이브러리입니다.
