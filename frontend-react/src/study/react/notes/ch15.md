## CSS 기초

**CSS** = selector + style

```css
h1 { color: green; font-size: 16px; }
/* h1: selector, color/font-size: property, green/16px: value */
```

### Selector 종류

| 종류 | 예 |
|---|---|
| Element selector | `h1 { }` |
| ID selector | `#id { }` |
| Class selector | `.class { }` |
| Universal selector | `* { }` |
| Grouping selector | `h1, h2, p { }` |
| Element의 상태와 관련된 selector | `:hover`, `:active`, `:focus`, `:checked`, `:first-child`, `:last-child` |

## 레이아웃과 관련된 속성

**display**

```css
div { display: none; }
```

- `none`: 화면에서 숨김
- `block`: 블록 단위로 배치
- `inline`: element를 라인 안에 넣음
- `flex`: 블록 레벨의 flex 컨테이너

**visibility**: `visible`, `hidden`

**position**

```css
div { position: static; }
```

- `static`: 원래 위치
- `fixed`: window(브라우저 창) 기준
- `relative`: 원래 위치에서 상대적으로
- `absolute`: 첫 번째 상위 element 기준

**가로·세로 길이**: `div { width: auto | value; }` (height도 같은 방식)

### flexbox

```
            flex container
  flex item    flex item    flex item
```

```css
div {
  display: flex;
}
```

- **flex-direction**: `row`(가로, 왼→오), `column`(세로, 위→아래), `row-reverse`(가로, 오→왼), `column-reverse`(세로, 아래→위)
- **align-items**: `stretch`(컨테이너 가득), `flex-start`, `center`, `flex-end`, `baseline`
- **justify-content**: `flex-start`(main axis 시작), `center`(중앙), `flex-end`, `space-between`, `space-around`

## font와 관련된 속성

- **font-family**: `font-family: Arial, Verdana;` — Arial이 없으면 Verdana를 사용
- **크기 단위**: `px`(pixel), `em`, `rem`, `vw`(viewport 기준)
- **font-weight**
- **font-style**: `normal`, `italic`(기울인 글자), `oblique`(글자를 기울인 것)
- **background-color**
- **border**(테두리)

## styled-components

**CSS를 JavaScript 안에서 Component로 만드는** 라이브러리입니다. 핵심 문법은 **tagged template literal** — 백틱(`` ` ``) 안에 **대체 가능한 expression(`${...}`)** 을 쓸 수 있는 문법입니다.

**(보충)** 이 챕터 예제입니다. 스타일이 붙은 `div`를 `styled.div`로 만들고, **props 값으로 스타일을 바꿉니다.**

```jsx
import styled from "styled-components";

const Wrapper = styled.div`
  padding: 1rem;
  display: flex;
  flex-direction: row;
  align-items: flex-start;
  justify-content: flex-start;
  background-color: lightgrey;
`;

const Block = styled.div`
  padding: ${(props) => props.padding};
  border: 1px solid black;
  border-radius: 1rem;
  background-color: ${(props) => props.backgroundColor};
  color: white;
  font-size: 2rem;
  font-weight: bold;
  text-align: center;
`;
```

```jsx
<Wrapper>
  <Block padding="1rem" backgroundColor="red">1</Block>
  <Block padding="3rem" backgroundColor="green">2</Block>
</Wrapper>
```

- `${(props) => props.padding}` 처럼 **함수를 넣으면 props 값에 따라 스타일이 달라집니다.**
- 위에서 배운 `display: flex`, `flex-direction`, `align-items`, `justify-content` 가 `Wrapper`에 그대로 쓰였습니다.

## 이 챕터의 예제 (Blocks)

**데모** 탭에서 `Wrapper`(회색 flex 컨테이너) 안에 `padding`과 `backgroundColor`가 다른 `Block` 3개(빨강·초록·파랑)가 가로로 놓입니다.

**콘솔 경고 두 가지** (원본 코드 그대로라서 뜹니다)

1. `map`으로 만든 `Block`에 `key`가 없다는 경고 → 10장에서 배운 key를 지정하면 해결됩니다.
2. `backgroundColor` 같은 props가 DOM까지 전달되어 "인식하지 못하는 prop" 경고가 납니다. styled-components v6는 props를 거르지 않고 DOM에 넘기기 때문이고, 해결 방법은 이름 앞에 `$`를 붙이는 **transient props**(`$backgroundColor`)입니다.
