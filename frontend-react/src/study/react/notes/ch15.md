## CSS 기초

**CSS** = selector + style

```css
h1 { color: green; font-size: 16px; }
/* h1: selector, color/font-size: property, green/16px: value */
```

### Selector 종류

| 종류 | 예 |
|---|---|
| Element selector | `h1 { }` |
| ID selector | `#id { }` |
| Class selector | `.class { }` |
| Universal selector | `* { }` |
| Grouping selector | `h1, h2, p { }` |
| Element의 상태와 관련된 selector | `:hover`, `:active`, `:focus`, `:checked`, `:first-child`, `:last-child` |

## 레이아웃과 관련된 속성

**display**

```css
div { display: none; }
```

- `none`: 화면에서 숨김
- `block`: 블록 단위로 배치
- `inline`: element를 라인 안에 넣음
- `flex`: 블록 레벨의 flex 컨테이너

**visibility**: `visible`, `hidden`

**position**

```css
div { position: static; }
```

- `static`: 원래 위치
- `fixed`: window(브라우저 창) 기준
- `relative`: 원래 위치에서 상대적으로
- `absolute`: 첫 번째 상위 element 기준

**가로·세로 길이**: `div { width: auto | value; }` (height도 같은 방식)

### flexbox

```
            flex container
  flex item    flex item    flex item
```

```css
div {
  display: flex;
}
```

- **flex-direction**: `row`(가로, 왼→오), `column`(세로, 위→아래), `row-reverse`(가로, 오→왼), `column-reverse`(세로, 아래→위)
- **align-items**: `stretch`(컨테이너 가득), `flex-start`, `center`, `flex-end`, `baseline`
- **justify-content**: `flex-start`(main axis 시작), `center`(중앙), `flex-end`, `space-between`, `space-around`

> **AI 코멘트**
>
> flexbox에서 가장 헷갈리는 점은 `justify-content`와 `align-items`가 **고정된 가로/세로가 아니라 축을 기준**으로 한다는 것입니다.
>
> - `justify-content` → **main axis**(주축, `flex-direction`이 정하는 방향)를 따라 정렬
> - `align-items` → **cross axis**(교차축, 주축에 수직인 방향)를 따라 정렬
>
> `flex-direction: row`(기본)이면 주축이 가로라서 `justify-content`가 가로 정렬이지만, `column`으로 바꾸면 주축이 세로가 되어 `justify-content`가 **세로 정렬**로 바뀝니다. 요소 사이 간격은 `gap` 속성으로 주면 편합니다.

## styled-components

**CSS를 JavaScript 안에서 Component로 만드는** 라이브러리입니다. 핵심 문법은 **tagged template literal** — 백틱(`` ` ``) 안에 **대체 가능한 expression(`${...}`)** 을 쓸 수 있는 문법입니다.

> **AI 코멘트**
>
> 이 챕터 예제입니다. 스타일이 붙은 `div`를 `styled.div`로 만들고, **props 값으로 스타일을 바꿉니다.**
>
> ```jsx
> import styled from "styled-components";
>
> const Wrapper = styled.div`
>   padding: 1rem;
>   display: flex;
>   flex-direction: row;
>   align-items: flex-start;
>   justify-content: flex-start;
>   background-color: lightgrey;
> `;
>
> const Block = styled.div`
>   padding: ${(props) => props.padding};
>   border: 1px solid black;
>   border-radius: 1rem;
>   background-color: ${(props) => props.backgroundColor};
>   color: white;
>   font-size: 2rem;
>   font-weight: bold;
>   text-align: center;
> `;
> ```
>
> ```jsx
> <Wrapper>
>   <Block padding="1rem" backgroundColor="red">1</Block>
>   <Block padding="3rem" backgroundColor="green">2</Block>
> </Wrapper>
> ```
>
> - `${(props) => props.padding}`처럼 **함수를 넣으면 props 값에 따라 스타일이 달라집니다.**
> - 위에서 배운 `display: flex`, `flex-direction`, `align-items`, `justify-content`가 `Wrapper`에 그대로 쓰였습니다.

> **AI 코멘트**
>
> 스타일을 적용하는 방법은 styled-components 말고도 여러 가지이고, 지금은 선택지가 갈립니다.
>
> - **일반 CSS 파일(+ CSS 변수)**: 가장 단순합니다. 이 프로젝트가 이 방식입니다. 전역 `style.css`에 색을 `--accent` 같은 CSS 변수로 모아 두어서, 테마를 한 곳에서 바꿀 수 있었습니다.
> - **CSS Modules**: 클래스 이름이 파일 단위로 자동으로 분리되어 이름 충돌이 없습니다.
> - **Tailwind CSS**: 미리 정의된 유틸리티 클래스를 조합하는 방식입니다.
> - **styled-components 같은 런타임 CSS-in-JS**: 컴포넌트와 스타일이 한 파일에 있고 props로 스타일을 바꾸기 편하지만, 스타일을 **실행 중에** 만들기 때문에 성능과 서버 렌더링 쪽 부담이 있어 신규 프로젝트에서는 다른 방식을 고르는 추세입니다.
>
> 오래된 프로젝트에서는 styled-components를 자주 만나기 때문에 읽을 줄은 알아 두는 것이 좋습니다.

## 이 챕터의 예제 (Blocks)

**데모** 탭에서 `Wrapper`(회색 flex 컨테이너) 안에 `padding`과 `backgroundColor`가 다른 `Block` 3개(빨강·초록·파랑)가 가로로 놓입니다.

> **AI 코멘트**
>
> 이 예제를 실행하면 브라우저 콘솔에 경고가 두 가지 뜹니다(원본 코드 그대로입니다).
>
> 1. `map`으로 만든 `Block`에 `key`가 없다는 경고 → 10장에서 배운 대로 고유한 key를 지정하면 해결됩니다.
> 2. `backgroundColor` 같은 props가 DOM까지 전달되어 "인식하지 못하는 prop" 경고가 납니다. styled-components v6는 props를 걸러 주지 않고 DOM에 그대로 넘기기 때문입니다. 해결 방법은 이름 앞에 `$`를 붙이는 **transient props**(`$backgroundColor`)입니다. `$`가 붙은 props는 스타일 계산에만 쓰이고 DOM에는 전달되지 않습니다.
