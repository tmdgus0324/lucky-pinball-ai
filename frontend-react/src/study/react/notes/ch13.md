## Composition(합성)이란?

**여러 Component를 조합해서 새로운 Component를 만드는 것**입니다.

### Containment (포함)

- *contain*의 의미로, **하위 Component를 포함하는 형태**의 합성 방법입니다.
- `Sidebar`나 `Dialog` 같은 **Box 형태의 Component**는 자신의 하위 Component가 무엇인지 **미리 알 수 없습니다.**
- 사용 방법: **`children`이라는 prop**을 사용해서 조합합니다.

> **AI 코멘트**
>
> 이 챕터의 `Card`가 바로 그 예입니다. 안에 무엇이 들어올지 모르는 빈 상자를 만들고, 들어온 내용을 `children`으로 그립니다.
>
> ```jsx
> function Card(props) {
>   const { title, backgroundColor, children } = props;
>
>   return (
>     <div style={{ margin: 8, padding: 8, borderRadius: 8, boxShadow: "0px 0px 4px grey",
>                   backgroundColor: backgroundColor || "white" }}>
>       {title && <h1>{title}</h1>}
>       {children}
>     </div>
>   );
> }
> ```
>
> ```jsx
> function ProfileCard(props) {
>   return (
>     <Card title="Inje Lee" backgroundColor="#4ea04e">
>       <p>안녕하세요. 소플입니다.</p>
>       <p>저는 리액트를 사용해서 개발하고 있습니다.</p>
>     </Card>
>   );
> }
> ```
>
> `<Card>` 태그 **안에 적은 내용 전체가 `children`** 으로 전달됩니다. `Card`는 안의 내용이 무엇인지 몰라도 되고, 쓰는 쪽이 마음대로 채웁니다.
>
> `children` 하나만으로는 빈 자리가 하나뿐이지만, **JSX 자체를 props로 넘기면** 여러 자리(슬롯)를 만들 수 있습니다.
>
> ```jsx
> <SplitPane left={<Contacts />} right={<Chat />} />
> ```

### Specialization (전문화, 특수화)

- 범용 Component를 **특수한 경우**로 구체화하는 방법입니다.
- 예: `WelcomeDialog`는 `Dialog`의 특이 케이스입니다.
- React에서는 이것도 **상속이 아니라 합성**을 사용해서 구성합니다.

> **AI 코멘트**
>
> `Dialog`라는 범용 Component에 props로 제목과 메시지를 넘겨서 `WelcomeDialog`를 만드는 모습입니다.
>
> ```jsx
> function Dialog(props) {
>   return (
>     <div>
>       <h1>{props.title}</h1>
>       <p>{props.message}</p>
>     </div>
>   );
> }
>
> function WelcomeDialog(props) {
>   return (
>     <Dialog title="어서오세요" message="우리 사이트에 방문하신 것을 환영합니다!" />
>   );
> }
> ```

## Inheritance(상속)

- 다른 Component로부터 **상속**받아 새로운 Component를 만드는 방식입니다.
- **React에서는 사용하지 않습니다.**

> **복잡한 Component를 쪼개서 여러 개의 Component로 만들고, 만든 Component들을 조합해서 새로운 Component를 만들자!**

> **AI 코멘트**
>
> Java 개발자에게는 "공통 기능은 부모 클래스에 두고 상속"이 익숙해서 낯설 수 있습니다. React 공식 문서도 수천 개의 컴포넌트를 만들어 봤지만 **컴포넌트 상속 계층을 권할 만한 경우를 찾지 못했다**고 설명합니다. 컴포넌트 사이의 코드 공유는 **합성**(화면 구조)과 **Custom Hook**(로직, 7장)으로 충분하기 때문입니다.
>
> 이 프로젝트의 `Layout`도 합성입니다. 사이드바를 그리고, `<Outlet />` 자리에 현재 페이지(게임·관리·공부하기)를 끼워 넣습니다. `Layout`은 어떤 페이지가 들어올지 모릅니다.

## 이 챕터의 예제 (ProfileCard / Card)

**데모** 탭의 초록색 카드가 `ProfileCard`입니다. `Card`는 `title`과 `backgroundColor` Props, 그리고 `children`을 받는 빈 상자이고, `ProfileCard`가 그 안에 소개 문장을 채웁니다. 코드 탭에서 `Card.jsx`와 `ProfileCard.jsx`를 나란히 보면 합성이 어떻게 이뤄지는지 볼 수 있습니다.
