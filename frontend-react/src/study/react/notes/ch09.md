## 조건부 렌더링이란?

**어떤 조건에 따라 렌더링 결과가 달라지는 것**입니다. 가장 기본은 `if`문입니다.

```jsx
function Greeting(props) {
  const isLoggedIn = props.isLoggedIn;

  if (isLoggedIn) {
    return <UserGreeting />;
  }
  return <GuestGreeting />;
}
```

## Truthy와 Falsy

JavaScript는 조건식에서 `true`/`false`가 아닌 값도 참/거짓으로 취급합니다.

**Truthy** — `true`는 아니지만 `true`로 여겨지는 값

```js
true
{}        // empty object
[]        // empty array
42        // number, not zero
"0", "false"   // string, not empty
```

**Falsy** — `false`는 아니지만 `false`로 여겨지는 값

```js
false
0, -0         // zero, minus zero
0n            // BigInt zero
'', "", ``    // empty string
null
undefined
NaN           // not a number
```

> **AI 코멘트**
>
> Java와 달리 JavaScript는 조건식에 boolean이 아닌 값도 넣을 수 있어서 흔한 실수가 생깁니다. **빈 배열 `[]`과 빈 객체 `{}`는 truthy**라서 `if (items)`는 비어 있어도 참입니다. 길이를 확인하려면 `if (items.length > 0)`처럼 명시적으로 비교하세요. 문자열 `"0"`과 `"false"`도 truthy입니다.

## Element Variables

Element를 **변수에 담아 두었다가** 조건에 따라 골라 렌더링합니다.

```jsx
function LoginButton(props) {
  return <button onClick={props.onClick}>로그인</button>;
}

function LogoutButton(props) {
  return <button onClick={props.onClick}>로그아웃</button>;
}

function LoginControl(props) {
  const [isLoggedIn, setIsLoggedIn] = useState(false);

  const handleLoginClick = () => {
    setIsLoggedIn(true);
  };

  const handleLogoutClick = () => {
    setIsLoggedIn(false);
  };

  let button;
  if (isLoggedIn) {
    button = <LogoutButton onClick={handleLogoutClick} />;
  } else {
    button = <LoginButton onClick={handleLoginClick} />;
  }

  return (
    <div>
      <Greeting isLoggedIn={isLoggedIn} />
      {button}
    </div>
  );
}
```

## Inline Conditions — `&&` 연산자

조건문을 **코드 안에 집어넣는** 방법입니다. `if`에 해당하는 경우 `&&` 를 씁니다.

- `true && expression` → `expression`
- `false && expression` → `false` (뒤쪽은 평가하지 않음 — **Short-Circuit Evaluation**)

```jsx
function Mailbox(props) {
  const unreadMessages = props.unreadMessages;

  return (
    <div>
      <h1>안녕하세요!</h1>
      {unreadMessages.length > 0 &&
        <h2>
          현재 {unreadMessages.length}개의 읽지 않은 메시지가 있습니다.
        </h2>
      }
    </div>
  );
}
```

아래 `Counter`는 `count`가 숫자일 때의 예입니다.

```jsx
function Counter(props) {
  const count = 0;

  return (
    <div>
      {count && <h1>현재 카운트: {count}</h1>}   {/* 화면에 "0"이 출력됨 */}
    </div>
  );
}
```

> **AI 코멘트**
>
> 위 `Counter`에서 `count`가 `0`이면 `&&` 뒤는 실행되지 않지만 **`0` 자체가 화면에 그려집니다.** `false`, `null`, `undefined`는 아무것도 그리지 않는데 **숫자 `0`은 그려지기** 때문입니다. `{count > 0 && ...}`처럼 **비교식으로 boolean을 만들어** 쓰는 것이 안전합니다.

## Inline If-Else — 삼항 연산자

`if-else`에 해당하는 경우 `? :` 연산자를 씁니다. → `condition ? true일 때 : false일 때`

```jsx
function UserStatus(props) {
  return (
    <div>
      이 사용자는 현재
      <b>{props.isLoggedIn ? '로그인' : '로그인하지 않은'}</b>
      상태입니다.
    </div>
  );
}
```

> **AI 코멘트**
>
> 삼항 연산자를 중첩(`a ? x : b ? y : z`)하면 읽기 어려워집니다. 조건이 셋 이상이면 조건문으로 일찍 반환(early return)하거나, 위의 Element Variables 방식이나 별도 컴포넌트로 나누세요.

## Component 렌더링 막기 — `null` 리턴

Component가 **아무것도 렌더링하지 않게** 하려면 `null`을 리턴합니다.

```jsx
function WarningBanner(props) {
  if (!props.warning) {
    return null;
  }

  return <div>경고!</div>;
}

function MainPage(props) {
  const [showWarning, setShowWarning] = useState(false);

  const handleToggleClick = () => {
    setShowWarning(prevShowWarning => !prevShowWarning);
  };

  return (
    <div>
      <WarningBanner warning={showWarning} />
      <button onClick={handleToggleClick}>
        {showWarning ? '감추기' : '보이기'}
      </button>
    </div>
  );
}
```

> 참고: 클래스 Component의 `render` 함수에서 `null`을 리턴해도 **생명주기 함수에는 영향이 없습니다.** (예: `componentDidUpdate`는 그대로 호출됩니다.)

> **AI 코멘트**
>
> `return null`(또는 `조건 && <A />`)로 **안 그리는 것**과 CSS로 **숨기는 것**(`display: none`)은 다릅니다. 안 그리면 컴포넌트가 **언마운트되어 state가 사라지고**, CSS로 숨기면 화면에서만 안 보일 뿐 **state가 유지**됩니다. 입력 중인 폼을 접었다 펼 때 값이 남아야 한다면 CSS로 숨기는 쪽이 맞습니다.

## 이 챕터의 예제 (LandingPage / Toolbar)

**데모** 탭의 `LandingPage`는 `isLoggedIn` state를 가지고, `Toolbar`에 `isLoggedIn`과 로그인/로그아웃 핸들러를 Props로 내려보냅니다.

- `Toolbar`는 이 챕터의 두 기법을 그대로 씁니다.
  - `{isLoggedIn && <span>환영합니다!</span>}` — **`&&`** 로 로그인했을 때만 환영 문구를 보여줍니다.
  - `{isLoggedIn ? 로그아웃 버튼 : 로그인 버튼}` — **삼항 연산자**로 버튼을 바꿉니다.
- 로그인 전에는 **로그인** 버튼만, 로그인 후에는 "환영합니다!"와 **로그아웃** 버튼이 보입니다.
- (코드 탭의 `Toorbar.jsx` 파일 이름은 원본 그대로 오타 상태입니다.)
