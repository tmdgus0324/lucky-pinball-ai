이 저장소에 실제로 적용된 설정입니다(`git config --list --show-origin`으로 확인).

## 이름과 이메일은 저장소별로

```
file:.git/config    user.name=tmdgus0324
file:.git/config    user.email=76435850+tmdgus0324@users.noreply.github.com
```

전역(`--global`)이 아니라 이 저장소에만 설정했습니다. 그리고 실제 메일 대신 GitHub가 주는 noreply 주소를 썼습니다. 공개 저장소의 커밋에는 작성자 메일이 그대로 보이기 때문에, 개인 메일이 드러나지 않게 하려는 것입니다.

회사 저장소에서는 반대로 회사 메일을 써야 커밋 작성자를 알아볼 수 있습니다. 개인 저장소와 회사 저장소를 한 PC에서 같이 쓴다면, 이렇게 저장소별로 설정하는 편이 섞이지 않습니다.

## 매번 보던 줄바꿈 안내

```
file:C:/Program Files/Git/etc/gitconfig    core.autocrlf=true
```

Git for Windows가 설치하면서 시스템 설정에 `core.autocrlf=true`를 넣어 두었습니다. 그래서 이 저장소에서 커밋할 때마다 이런 안내가 나왔습니다.

```
warning: in the working copy of 'frontend-react/src/study/git/chapters.ts', LF will be replaced by CRLF the next time Git touches it
```

에디터가 LF로 파일을 만들고, Git이 "다음에 꺼낼 때 CRLF로 바꾸겠다"고 알려 주는 것입니다. 저장소 안에는 LF로 들어가므로 리눅스 서버(Render)에서 빌드할 때는 문제가 없었습니다. 오류가 아니어서 따로 고치지 않았습니다.

## 원격 저장소와 로그인

```
remote.origin.url=https://github.com/tmdgus0324/lucky-pinball-ai.git
```

```
file:C:/Program Files/Git/etc/gitconfig    credential.helper=manager
```

HTTPS 주소를 쓰고, push할 때의 로그인은 Git for Windows에 들어 있는 Git Credential Manager가 처리합니다. 처음 한 번 브라우저로 로그인하면 윈도우 자격 증명 저장소에 보관해 두고, 그 뒤로는 다시 묻지 않습니다. 저장소 만들기나 CI 결과 보기에는 GitHub CLI(`gh`)를 따로 로그인해서 씁니다.

노트북에서 같은 저장소를 쓰려면 clone한 뒤 로그인과 저장소별 이름·이메일 설정을 다시 해야 합니다. 이 설정들은 `.git/config`와 내 PC에 있고, 저장소를 따라오지 않기 때문입니다.
