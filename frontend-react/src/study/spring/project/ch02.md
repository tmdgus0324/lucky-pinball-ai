핀볼 게임 백엔드의 구조와 설정입니다.

## 패키지 구조

기능(도메인)별로 패키지를 나눴습니다. 컨트롤러·서비스·저장소를 각각 모으는 방식(`controller/`, `service/` …)보다, 관련된 코드가 한곳에 모여 있어서 찾기 쉽습니다.

```
com.luckypinball
├── LuckyPinballApplication.java
├── player/    참가자 등록
├── fortune/   운세 조회, Claude 호출
├── game/      게임 생성·결과
├── admin/     관리자 로그인과 조회
├── common/    필터, 예외 처리, 오류 로그
└── config/    CORS 설정
```

## application.yml의 기본값 문법

```yaml
server:
  # 환경변수 PORT가 있으면 그 값을, 없으면 8080을 쓴다.
  port: ${PORT:8080}
```

`${이름:기본값}` 형식입니다. 운영(Render)은 `PORT` 환경변수로 포트를 정해 주고, 로컬에서는 기본값 8080으로 뜹니다. 같은 파일 하나로 두 환경을 맞춘 방법이고, 4장에서 자세히 봅니다.

## Gradle 설정에 넣은 인코딩

```gradle
tasks.named('bootRun') {
    jvmArgs '-Dfile.encoding=UTF-8'
}
tasks.withType(JavaCompile).configureEach {
    options.encoding = 'UTF-8'
}
```

윈도우는 기본 인코딩이 한글 윈도우용(MS949)이라 한글 주석과 로그가 깨질 수 있어서, 컴파일과 실행 모두 UTF-8로 맞췄습니다.

## CI에서 쓰는 Gradle 명령

GitHub에 push할 때마다 GitHub Actions가 `./gradlew test`를 돌립니다. 테스트가 실패하면 push한 사람에게 알림이 갑니다. 테스트는 17장에서 다룹니다.
