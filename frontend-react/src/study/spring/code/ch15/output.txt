# 4) 서버를 끄지 않고 로그 레벨 바꾸기
$ curl http://localhost:8080/actuator/loggers/com.example.reservation
{"configuredLevel":"INFO","effectiveLevel":"INFO"}

$ curl -X POST -H "Content-Type: application/json" \
       -d '{"configuredLevel":"DEBUG"}' \
       http://localhost:8080/actuator/loggers/com.example.reservation
(204 No Content)

$ curl http://localhost:8080/reservations/2
