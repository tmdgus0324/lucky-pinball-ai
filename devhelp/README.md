# devhelp

로컬 실행 방법과 작업 기록을 모아 둔 폴더입니다. 작업 기록에는 무엇을 왜 바꿨고 어떤 문제를 만났는지 적었습니다. 지금 코드 기준 설명은 [devdocs](../devdocs/README.md)에 있습니다.

## 로컬 실행

필요한 것: JDK 17, Node.js. 로컬 DB는 H2 파일이라 따로 설치할 것이 없습니다.

```bash
# 백엔드: http://localhost:8080
cd backend
./gradlew bootRun
./gradlew test

# 프론트엔드: http://localhost:5173
cd frontend-react
npm install
npm run dev
```

| 환경변수 | 용도 | 없으면 |
|---|---|---|
| `ANTHROPIC_API_KEY` | Claude 운세 생성 | 생년월일 없이 참여하는 참가자만 가능 |
| `ADMIN_PASSWORD` | 관리자 로그인(아이디는 `ADMIN_USERNAME`, 기본 `admin`) | 관리자 로그인이 항상 거절됨 |
| `VITE_API_BASE` | 프론트가 호출할 백엔드 주소 | `http://localhost:8080` |

처음 개발 환경을 준비한 과정(JDK 설치, 프로젝트 생성)은 [01_MVP_구현_기록](./01_MVP_구현_기록.md)의 `[구 01]` 절에 있습니다.
