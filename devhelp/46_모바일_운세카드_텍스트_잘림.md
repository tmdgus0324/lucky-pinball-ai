# 46. 모바일 운세 카드 텍스트 잘림

배포 검증 때(devhelp/28) "모바일에서 운세 카드 텍스트가 길면 잘린다"고 적어 두고 미뤘던 문제다. 기록이 한 줄뿐이라 먼저 재현부터 했다.

## 1. 재현 방법 — 백엔드 없이

Playwright로 화면을 열고, **API 응답을 브라우저에서 가짜로 바꿔 끼웠다**(`page.route`). 백엔드·Claude 없이 원하는 이름과 운세 문구를 마음대로 넣을 수 있다.

- 넣은 값: 평범한 이름 / **띄어쓰기 없는 긴 한글 이름** / **띄어쓰기 없는 긴 영문 이름** / 두 줄 넘는 긴 운세 문구 / 띄어쓰기 없는 긴 영문 문구
- 폭: 320 / 360 / 390 / 412px(휴대폰), 1280px(데스크톱)
- 측정: 카드마다 내용이 카드 폭을 넘는지(`scrollWidth > clientWidth`), 페이지 전체가 가로로 넘치는지

## 2. 원인 두 가지

1. **띄어쓰기 없는 긴 영문이 카드 밖으로 잘렸다.** 모든 폭에서 해당 카드의 내용이 카드 폭을 넘었고, 끝부분이 보이지 않았다. 영문은 띄어쓰기에서만 줄바꿈되기 때문이다.
2. **한글이 단어 중간에서 줄바꿈됐다.** "이어지는 날입니/다.", "하루/가", "보세/요."처럼 끊겨서 글자가 잘린 것처럼 보였다. 브라우저 기본값(`word-break: normal`)은 한글을 **아무 글자 사이에서나** 줄바꿈한다. 실제 Claude 문구는 한글이라 기록된 "잘림"은 주로 이쪽이었을 가능성이 높다.

페이지 전체가 가로로 넘치지는 않았다(카드 안에서만 문제).

## 3. 수정 — CSS 몇 줄

```css
.fortune-card {
  min-width: 0;              /* 그리드 칸이 긴 내용 때문에 늘어나지 않게(기본값 min-width: auto) */
  word-break: keep-all;      /* 한글은 띄어쓰기에서만 줄바꿈 */
  overflow-wrap: anywhere;   /* 그래도 한 줄에 안 들어가는 긴 단어만 강제로 줄바꿈 */
}

.fortune-card .name { display: flex; align-items: flex-start; }   /* 공 색 점 옆에서 이름이 줄바꿈 */
```

- `keep-all`만 쓰면 띄어쓰기 없는 긴 한글 이름이 통째로 한 단어가 되어 다시 넘친다. `overflow-wrap: anywhere`가 그 경우에만 끊어 준다. 두 규칙을 **같이** 써야 한다.
- 처음엔 긴 이름이 통째로 다음 줄로 넘어가 **공 색 점만 첫 줄에 혼자 남았다.** 이름 줄을 flex로 바꿔 점과 이름을 나란히 두었다.
- 앱의 다른 설명 문구(`.desc`)는 이미 `keep-all`을 쓰고 있었는데 카드에만 빠져 있었다.
- 레거시 프론트엔드(`frontend/`)의 같은 카드에도 줄바꿈 규칙을 똑같이 넣었다.

## 4. 검증

- 4가지 휴대폰 폭과 데스크톱에서 **모든 카드의 넘침 0**, 페이지 가로 넘침 없음.
- 화면으로 확인: "날입니다.", "보세요."가 한 덩어리로 유지되고, 긴 영문 이름·문구도 카드 안에서 줄바꿈되며, 공 색 점과 이름이 나란히 놓인다.
- `tsc`, `lint`, `build` 통과.
- 실제 휴대폰 기기로는 확인하지 않았다(브라우저의 휴대폰 폭 흉내로 확인).
