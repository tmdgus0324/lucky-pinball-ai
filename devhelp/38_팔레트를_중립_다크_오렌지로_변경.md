# 38. 팔레트를 보라에서 중립 다크 + 오렌지로 바꾼 과정

전체가 남보라 배경에 보라 버튼이라 "AI 기본 세팅" 같다는 지적에서 시작했다. 먼저 색이 왜 그렇게 됐는지부터 확인하고, 바꿀 방향이 참고 사이트와 겹치지 않는지 따져본 뒤 적용했다.

## 1. 보라는 어디서 왔나

- 첫 커밋(9/22)의 초기 목업(`plan/mockups/style.css`)에 이미 `#7c5cff`(보라 버튼), `#ffd166`(금색), 남보라 배경이 있었다. 색을 고른 이유나 사용자가 지정한 기록은 문서 어디에도 없다.
- 이후 React 마이그레이션까지 "디자인 결정이라 바꿀 이유가 없다"며(devhelp/08) 그대로 이어받았다. 이 게임에 맞춰 고른 색이 아니라 초기 기본값을 계속 쓴 것이다.
- 이미지 파일은 없다. 화면은 전부 CSS와 이모지이고 공은 색 원이다. 다만 `public/favicon.svg`가 **Vite 기본 템플릿 로고(보라 번개)** 그대로였다.

## 2. 참고 사이트(lazygyu/roulette)와 겹치지 않는가

참고 사이트의 정체성은 **순검정 배경 + 시안 네온 글로우 + 중간 회색(#666 정도) 하단 패널 + 파란 토글 + 풀스크린 캔버스**다(스크린샷과 소스의 기본 도형색 `cyan/yellow/white`, 시안 블룸 기준).

| | 참고 사이트 | 새 팔레트 |
|---|---|---|
| 강조색 | 시안·파랑 | 오렌지(`#ff7a1a`) |
| 배경 | 순검정 | 어두운 무채색(`#0f1115`) |
| 글로우 | 네온 | 없음 |
| 구조 | 풀스크린 + 하단 패널 | 사이드바 + 카드 |

시안/파랑 포인트와 글로우를 쓰지 않았고, 패널도 중간 회색이 아니라 거의 검정에 가까운 회색(`#171a20`)에 얇은 테두리로 갔다. 후보 중 시안 네온(A안)이 참고 사이트와 가장 가까워서 제외했다.

| 변수 | 이전 | 이후 | 비고 |
|---|---|---|---|
| `--bg` / `--panel` / `--panel-2` | `#14121f` / `#1e1b2e` / `#262238` | `#0f1115` / `#171a20` / `#1f232b` | |
| `--border` | `#322c4a` | `#2a2f39` | |
| `--text` / `--muted` | `#f1eefc` / `#a79fc4` | `#eceff4` / `#9aa3b2` | |
| `--accent-2` (주요 버튼) | `#7c5cff` | `#ff7a1a` | |
| `--accent` (당첨·결승선) | `#ffd166` | 그대로 | |
| `--on-accent-2` (신규) | - | `#1a1208` | 주황 버튼 위 글자 |
| `--wall` (신규) | - | `#3a404c` | 맵의 벽·선반 (테두리색과 분리해서 맵에서 형체가 보이게) |

- 변수 밖에 박혀 있던 보라 계열 값도 정리: 보드 배경 그라데이션, 못 색, 공 글자색, 결과 배너 그라데이션·오버레이 배경. 회전 막대는 빨강→금에서 **주황→금** 그라데이션으로.
- 버튼 글자를 흰색에서 어두운 색으로: 흰 글자는 주황 위에서 대비가 약해서(2.6 정도) 어두운 글자로 바꿨다.
- 파비콘을 이 게임의 공(주황→금 그라데이션 공 + 못 3개)으로 교체하고, 모바일 주소창 색(`theme-color`)을 새 배경색에 맞췄다.
- **일부러 안 바꾼 것**: 운세 등급 색(`tier-3` 보라는 "에픽" 희귀도 관례), 공 8개의 구분용 팔레트(8색이 필요해서 보라·시안 포함), 로고의 🎱 이모지(OS 폰트가 그리는 색이라 CSS로 못 바꿈).

## 4. 검증

- **보라 잔여 자동 탐지**: 게임 화면과 관리자 화면의 모든 요소에서 계산된 색(글자·배경·테두리·outline)을 HSL로 바꿔 hue 250~295°, 채도 12%↑를 찾았다(공 팔레트와 `tier-3`은 제외). 결과 **0건**.
- **명암비**(WCAG): 주황 버튼의 글자 **7.1:1**(기준 4.5), 비활성 버튼 6.19:1, 설명 글자(`--muted`)가 패널 위에서 6.85:1.
- 게임 화면 → 8명 게임 진행 → 결과 오버레이 → 관리자 화면까지 화면 캡처로 확인했고 페이지 오류는 없었다.

## 5. 남은 것

- 레거시 `frontend/`는 보라 팔레트 그대로다. 주력은 React이고 레거시는 물리 동기화용으로만 유지 중이라 이번엔 건드리지 않았다.
- 색이 변수로 모여 있어서 다른 팔레트로 바꾸려면 `:root` 값과 위 4곳(보드·못·공 글자·배너)만 보면 된다.
