# 47. 관리자 "가중치 임의 조정" 기능 제거

MVP 때부터 관리자 화면에 "가중치 임의 조정" 패널과 `POST /api/admin/fortune/override` API가 있었다. 실제로는 항상 `501 Not Implemented`를 돌려주는 **자리만 잡아 둔 스텁**이었다. 로드맵의 다음 순서로 구현하려다가 **하지 않기로 결정**하고 모두 걷어냈다.

## 왜 뺐나

- 구현하려면 "덮어쓴 점수를 한 판만 쓸지 계속 쓸지", "이력을 어떻게 남길지", "AI 캐시(같은 신원 재사용)와 어떻게 섞일지" 같은 규칙을 새로 정해야 했다. 게임의 재미나 포트폴리오 설명에 비해 얻는 것이 작았다.
- 동작하지 않는 버튼이 관리자 화면에 "준비 중"으로 계속 남아 있는 것이 오히려 완성도를 떨어뜨렸다.

## 무엇을 지웠나

| 위치 | 내용 |
|---|---|
| 서버 | `AdminController`의 `/api/admin/fortune/override` 엔드포인트와 요청 레코드, 더 이상 쓰이지 않는 `ApiException.notImplemented()` |
| React 화면 | `OverrideForm` 컴포넌트, 관리자 화면의 패널과 "가중치 조정(예정)" 안내 문구, API 함수 `adminOverrideFortune`, `.override-form` CSS |
| React 정리 | 오류 로그를 다시 불러오는 `reloadKey`는 가중치 패널만 쓰던 것이라 함께 제거 |
| 레거시 화면 | `admin.html`의 패널, `admin.js`의 처리 코드, `api.js` 함수, CSS. 함께 남아 있던 "인메모리 로그(영속화는 Phase 2)" 안내 문구도 지금 상태(DB 저장)로 고침 |
| 문서 | API 명세에 "제거됨" 표시, backlog B4를 "하지 않기로 함"으로, README 보완 예정 목록에서 제외 |

- 과거 계획 문서(`plan/01`, `plan/06`, 목업)는 당시 기록이라 그대로 두었다.
- `AdminController`의 클래스 설명에 남아 있던 "인증 없음(MVP 한정)"도 지금 상태(관리자 토큰 필요)에 맞게 고쳤다.

## 확인

- 서버에 남은 참조가 없는지 검색으로 확인(`override`, `notImplemented`).
- 백엔드 테스트 99개 통과(키 환경변수 없는 CI 조건), 프론트 `tsc`·`lint`·`build` 통과, 레거시 JS 문법 확인(`node --check`).
- 브라우저에서 관리자 화면에 **참가자·게임·오류 로그·AI 연결 확인 4개 패널만** 남고 "가중치" 문구가 없는 것을 확인.
- 이제 이 주소로 요청하면 404다(없는 경로).
